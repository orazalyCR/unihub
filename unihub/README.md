# UniHub — рабочая локальная версия

## Запуск

1. Откройте `start.bat` двойным щелчком. Установленный Python 3.10+ обязателен; дополнительных пакетов не нужно.
2. Браузер откроется автоматически: обычно http://localhost:8000.
3. Нажмите **Create an account**, зарегистрируйтесь и пользуйтесь сайтом.

## Публичный запуск

Проект поддерживает запуск на хостингах с переменными `PORT` и `HOST`. В репозитории есть `../render.yaml` для Render: сервис запускается командой `python server.py`, слушает `0.0.0.0` и проверяется через `/api/health`.

Повторный запуск открывает уже работающий сервер этой копии. Если порт занят другим приложением, выбирается свободный порт от 8000 до 8009. Подробности запуска находятся в `launcher.log`. Для запуска в терминале и остановки через Ctrl+C: `python server.py`.

## Реализованные сценарии

- **Аккаунты:** регистрация, вход, выход, редактирование имени, университета, email, описания и интересов; смена пароля завершает все сессии.
- **Лента:** создание, редактирование и удаление своих постов; лайки, комментарии, удаление своего комментария; подписки на авторов; фильтры университета, категории и подписок.
- **Сообщество:** действительные участники университета, создание клубов, вступление/выход, список участников и связь с ними.
- **StudyMate:** создание и редактирование своего профиля, предметы и фильтры; создание учебных групп, вступление и участники.
- **CoLiving:** создание и редактирование своего объявления, бюджет, район и предпочтения; фильтры; связь через сообщения.
- **Marketplace:** публикация, редактирование, удаление товара; фото PNG/JPEG/WebP до 2 МБ, цена, категория, состояние, отметка Sold, контакт с продавцом. Расчёт и передача товара согласовываются в переписке; платёжного сервиса нет.
- **События:** создание, редактирование, закрытие и удаление; дата/место; Interested/Going и отмена ответа; организатор видит участников.
- **Lost & Found:** публикация и редактирование Lost/Found, связь с автором и закрытие найденного/возвращённого предмета.
- **Opportunities:** публикация предложений, дедлайн, отклик/отмена; автор видит откликнувшихся и может им написать.
- **Student Discounts:** пользовательские предложения, условия, срок, сохранение и показ промокода. Это объявления участников, а не подтверждённые партнёрские программы.
- **Сообщения:** переписка между настоящими зарегистрированными аккаунтами, история и отметка прочтения; обновление примерно каждые 5 секунд, когда вкладка активна.
- **Уведомления:** новые сообщения, комментарии и ответы на объявления; переход к соответствующему разделу, отметка прочитанными.
- **Профиль:** действительные счётчики, свои записи, отклики, группы и объявления.
- **Университет:** выбранное сообщество сохраняется в аккаунте, а не только в браузере.
- **Оформление:** светлая и тёмная тема (Settings → Appearance), переключатель в шапке сайта; по умолчанию следует системной теме устройства, выбор сохраняется в браузере.

## База данных и сохранность

`unihub.db` создаётся автоматически возле `server.py`. Это настоящая SQLite-база: данные переживают обновление страницы, выход и перезапуск. Фото объявлений также хранятся в ней.

Новая база пустая: контент добавляют зарегистрированные участники. Старые демонстрационные записи из архива без владельцев остаются в старой базе, если она есть, но не показываются как реальные аккаунты. Существующие пользовательские посты и товары сохраняются. Миграции добавляют таблицы и поля без сброса базы.

Для резервной копии работающей базы можно выполнить:

```
python backup.py
```

Получится согласованная копия SQLite в папке `backups/`. Не удаляйте `unihub.db`, если хотите сохранить аккаунты и записи. Папку проекта можно переносить вместе с базой, предварительно остановив сервер.

Пароли хешируются scrypt с индивидуальной солью. Сессии — HttpOnly/SameSite-cookie, в базе хеш токена. Проверки прав выполняются сервером. Приватные email и даты рождения не передаются другим участникам; сообщения доступны только отправителю и получателю. Выбор университета не является подтверждением статуса студента.

## Проверка

```
python test_integration.py
```

10 интеграционных тестов запускают отдельный сервер на случайном локальном порту и временную базу. Проверяются аккаунты, приватность, права владельцев, все разделы, ответы, фотографии, смена пароля, целостность БД и сохранение после перезапуска. Рабочая база тестами не изменяется.

Интерфейс дополнительно проверен в браузере: вход, загрузка всех страниц, публикация поста, комментария, учебного профиля, товара и события, переписка, отклик на событие, редактирование профиля, мобильная и настольная компоновка.

## Границы этой версии

Это локальное многопользовательское приложение: сервер слушает только `127.0.0.1`. Для проверки двух аккаунтов откройте обычное и приватное окно браузера. Другие компьютеры через интернет пока не подключены — именно такой режим выбран для этой версии. Стандартный HTTP-сервер Python предназначен для этого локального запуска, не для публичного хостинга.

Интерфейс сохранён на английском, как в исходном проекте. Письма на email, внешние платежи, проверка документов студентов, интеграции с работодателями и сервисами жилья не подключались. Главное фото сохраняет исходную внешнюю ссылку; без интернета основной функционал продолжает работать, но фото может не загрузиться.

## Исходники

- `server.py` — HTTP, аккаунты, базовые записи и миграции.
- `features.py` — функциональные разделы, переписка, реакции и проверки доступа.
- `site/app.js`, `site/styles.css`, `site/*.html` — интерфейс.
- `launcher.py`, `start.bat` — запуск двойным щелчком.
- `backup.py` — резервное копирование SQLite.
- `test_integration.py` — автоматическая проверка.
